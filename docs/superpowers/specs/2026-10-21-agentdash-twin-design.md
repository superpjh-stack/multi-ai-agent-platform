## 2. 배치 · 데이터

### 2.2 배치 규칙 T-01~T-07 (서버 계산 · 결정적)
- T-01 라인 순서: 살아 있는 설비가 있는 라인 먼저 → 마지막 활동 최근 순 → 이름.
- T-02 열 = 깊이 (세션 0).
- T-03 행 = 부모 아래 자식을 `started_at` 순으로 깊이 우선 탐색한 순서.
- T-04 칸 크기 고정 · 칸 사이 간격 고정 · 설비 상자 겹침 0.
- T-05 DONE · FAILED 이고 끝난 지 30 분 넘은 설비는 부모 안 「+N 완료」 칩으로 접는다.
- T-06 그래도 전체 설비 > 300 이면 오래된 라인부터 라인 머리 한 줄로 접는다 (D-02 G6 와 같은 상한).
- T-07 같은 입력(DB 상태 + now)이면 같은 출력.
- 범위: 기본 「살아 있는 것 + 최근 24 시간」, 필터 기간 · 프로젝트 (D-02 와 같음).

### 2.3 API `GET /api/v1/twin?since=&project=` (13 → 14)
```
{ generated_at,
  lines: [{ key, name, live, counts{STATE:n}, box{x,y,w,h},
            machines: [{ key, kind, name, parent, state, rule, since, elapsed_s,
                         tool, target, out_total, out_est_total, cost_est_usd,
                         spark: [30 정수], folded: n, box{x,y,w,h} }],
            pipes: [{ src, dst, kind, at }] }],
  links: [{ src, dst, count }],
  folded_lines: n }
```
- `spark` = 최근 30 분 분당 **추정 보정 출력**(`output_est` 있으면 그 값, 없으면 `output_tokens`) `[추정]` — 기록값은 서브에이전트에서 D-17 때문에 거의 0.
- `tool` · `target` = 그 에이전트의 결과 없는 마지막 `tool_call` (이미 ≤ 300 자 저장값). 본문 없음.
- 누적 = `usage.totals(con, key)` 와 같은 숫자.

### 2.4 실시간 (탭당 SSE 1 연결 공유)

- `agent.new` · `edge.new` → 배관 입자 한 번 → `/api/v1/twin` 다시 받기 (1 초 묶음).
- `agent.usage` → 스파크 5 초 묶음 다시 받기.

## 3. 화면 · 애니메이션

### 3.1 배치
- `/` = 평면도(≈ 70 %) + 오른쪽 패널(≈ 30 %). 1000 px 미만이면 패널이 아래로. 390 px 페이지 가로 스크롤 0, 평면도는 자기 카드 안에서만 이동.
- 패널 = 기존 D-01 전부: 상태 KPI 8 · 내 차례(복사 버튼) · 선택한 설비 요약 · 오늘 KPI · 상위 5 · 최근 상태 변화 · 파싱 오류. 예산 띠는 맨 위.
- 평면도 확대 · 축소 · 이동 (버튼 · Ctrl+휠 · 끌기) · 「맞춤」.

### 3.2 설비
- 이름(24 자) · 상태 · 경과 · 지금 도구 · 30 분 스파크 · 지금 분당 `[추정]` · 누적 출력 · 추정 보정 비용.
- 색 = §4.1 상태 8 토큰. RUNNING 2 초 맥박 · WAITING_* 경광등 + 「!」 · STALE 알람 삼각형 1 초 깜빡임 · SLEEPING 깰 시각 · DONE 흐림.
- 클릭 → 패널 요약(규칙 · 부모 · 자식), 더블클릭 · Enter → D-03.

### 3.3 배관
- spawn: 실선 관, 자식 RUNNING 동안 느린 입자 흐름.
- 새 spawn: 굵은 입자 한 번 + 새 설비 0.4 초 나타남.
- handback: 자식 → 부모 거꾸로 입자 한 번 → 설비 DONE 흐림.
- message: 라인 간 점선 컨베이어, 굵기 = 횟수.
- `prefers-reduced-motion` → 깜빡임 · 입자 0, 색 · 배지만.

### 3.4 접근성
설비마다 `role="button"` · `tabindex="0"` · `aria-label`(이름 · 상태 · 경과), 키보드 순회. 화면 낭독기용 숨김 표 병행.
